# MetaBank Demo — V3

دموی فارسی و راست‌چین متابانک، با هویت بصری MetaBank - V 0.9.1.

## نسخه‌ها
- V1: فایل‌های اولیهٔ ارائه‌شده توسط سهیل، در Google Drive.
- V2: دموی منتشرشده با رنگ‌ها، نشان و فونت‌های ارائه؛ snapshot commit 46e23790f8da2d09cba597951b110e5de58806fd. پیش از تغییرات V3، فایل‌های کامل و ZIP در پوشهٔ Demo ذخیره شدند.
- V3: پنج مقصد اصلی، دارایی‌های یکپارچه، کارت‌ها، پرداخت، بازار، خدمات و فضای کسب‌وکار.

## اجرا
index.html را باز کنید، یا همین پوشه را با یک وب‌سرور استاتیک سرو کنید. metabank-preview.html یک نسخهٔ مستقل با فونت‌ها، نشان و کدهای داخلی است.

## امکانات
- خانه؛ حساب‌های بانکی، BTC، USDT، ETH و توکن دارایی.
- دارایی‌ها؛ فیلتر نوع، جزئیات، سه کارت و کنترل وضعیت نمایشی کارت.
- پرداخت و انتقال؛ مرور و تأیید انتقال نمونه، دریافت، تاریخچه و فیلتر، مخاطبان و افزودن مقصد، خروجی CSV و نمای چاپ/PDF.
- بازار؛ خریدوفروش با قیمت ثابت فرضی، تغییر موجودی نمونه و ثبت تراکنش؛ معرفی معاملات مستقیم و توکن‌های دارایی.
- خدمات؛ درخواست توکن، چرخهٔ بررسی و انتشار نمایشی، اسناد نمونه، درخواست اعتبار، لینک ابزارهای مستقل.
- کسب‌وکار؛ درخواست پرداخت، API و وب‌هوک نمایشی، جدول تیم.
- تنظیمات؛ واحد ارزش‌گذاری، روشن/تیره/سیستم، برچسب‌های اصلی انگلیسی/فارسی، نمایش موجودی و صدای اعلان.
- دستیار سناریویی؛ پاسخ‌های محلی برای هدایت کاربر. به مدل زبانی متصل نیست.
- manifest، favicon و Apple touch icon از نشان اصلی اسلاید استخراج شده‌اند. نصب هوم‌اسکرین برای اجرای آنلاین است؛ پشتیبانی آفلاین ادعا نمی‌شود.

## حدود دمو
تمام نام‌ها، حساب‌ها، نشانی‌ها، نرخ‌ها و عملیات مالی نمونه‌اند. ورود احراز هویت واقعی نیست. هیچ پرداخت، انتشار قرارداد، اعتباردهی، فراخوانی وب‌هوک یا API بانکی انجام نمی‌شود. تغییرات نمونه با کلید metabank-v3-demo در مرورگر ذخیره می‌شوند؛ از تنظیمات می‌توان آن‌ها را بازنشانی کرد. انگلیسی‌سازی محدود به برچسب‌های اصلی است.

لینک‌های soheil.info، RialChange و RPCNode مستقل‌اند و به موجودی و نشست متابانک متصل نیستند. وضعیت بازشدن رابط به معنی تأیید عملکرد شبکه یا قرارداد نیست.
